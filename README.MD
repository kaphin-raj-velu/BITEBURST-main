# 🍽️ Smart Food Ordering System

A voice-enabled food ordering platform designed to improve accessibility for visually impaired users. The system allows users to browse menus, place orders, and receive real-time audio feedback using voice commands, creating an inclusive and user-friendly ordering experience.

## 🚀 Features

- 🎤 Voice-based menu navigation
- 🗣️ Speech recognition using Web Speech API
- 🔊 Real-time audio feedback for user interactions
- 🍔 Dynamic food menu display
- 🛒 Food ordering functionality
- ♿ Accessibility-focused design for visually impaired users
- 📱 Responsive user interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js

### Database
- MySQL

### APIs
- Web Speech API

## 📋 System Workflow

1. User opens the application.
2. Voice commands are used to navigate through food categories and menu items.
3. The system provides audio feedback for each action.
4. User selects food items using voice commands.
5. Order details are processed and stored in the database.
6. Order confirmation is provided through voice and visual feedback.

## 🎯 Objectives

- Improve accessibility in food ordering systems.
- Enable visually impaired users to place orders independently.
- Provide a seamless and intuitive voice-controlled experience.
- Enhance user interaction through speech-based technologies.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/smart-food-ordering-system.git
```

### Navigate to Project Directory

```bash
cd smart-food-ordering-system
```

### Install Dependencies

```bash
npm install
```

### Configure Database

1. Create a MySQL database.
2. Import the SQL schema.
3. Update database credentials in the configuration file.

### Start the Server

```bash
npm start
```

### Open in Browser

```text
http://localhost:3000
```
